# Domain 5: Software Ecosystem Phase Transition (κ-software)

**Status:** Proposed / Theoretical  
**Anchor:** Sean Harpur (TechRadar Pro Perspectives, May 2026)  
**Connected to:** Assembly theory, Cloud-9 κ-framework, Domain 4 (biological longevity)

## Definition

A software ecosystem crosses its phase transition when the rate of user adoption / integration exceeds the rate of complexity / friction / onboarding cost.

**κ_software(t) = A(t) / F(t)**

- **A(t)** = adoption velocity (new users per day, integrations per week, active feedback loops)
- **F(t)** = friction coefficient (time-to-first-useful-result, cognitive overhead, setup failures)

**Transition condition:** κ > 1.0 → ecosystem becomes self-accelerating (network effects, toolchains, community content, job creation).  
κ < 1.0 → remains a research curiosity or specialist tool.

## Prediction: Quantum Software

Per Harpur (2026): Quantum computing currently has κ_software < 0.5 for non-specialists. Hardware-focused metrics dominate.

**Crossing event predicted** when:
1. Quantum-powered creative tool (game engine, generative music, VFX) achieves *lower friction* than classical alternative for a nontrivial use case
2. Developer tooling (Q#, hybrid compilers, plugins) reaches "install, write, run under 5 minutes"

**Estimated κ_c**: 2028–2030, κ ≈ 1.0–2.0 initially, then accelerating.
